# Współtworzenie

Projekt przyjmuje małe, konkretne usprawnienia: poprawki analizy zapytań, testy przypadków brzegowych, dostępność oraz dokumentację.

1. Opisz problem i przykład danych fikcyjnych.
2. Dodaj lub uzupełnij test w `tests/`.
3. Zachowaj zasadę, że wynik wymaga zatwierdzenia przez człowieka przed wysłaniem.
4. Nie dodawaj danych prawdziwych klientów, haseł ani kluczy.
